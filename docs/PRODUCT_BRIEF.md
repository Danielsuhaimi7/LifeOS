# LifeOS product brief

A private, single-user personal app for desktop and iPhone.

## Planned areas
Tasks and recurring tasks; calendar and appointments; notes and checklists; accounts, transactions, bills, loans, budgets, savings, assets, reports, and exports; dashboard, search, settings, and backup.

## Product conventions
- Responsive web app with an installable PWA path
- Light, minimalist interface with off-white surfaces and muted sage accents
- MYR stored as integer sen
- Display dates as DD/MM/YYYY
- Timezone Asia/Kuala_Lumpur; Sunday week start

## Cost and delivery
Target RM0/month. Check free-tier limits and reminder feasibility before enabling cloud services. Paid services require explicit approval. Build one ticket at a time.
